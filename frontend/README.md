# NEXUS Frontend

Frontend application for the NEXUS platform built with Vite, React, and TypeScript.

## Prerequisites

- Node.js (v20+ recommended)
- npm

## Getting Started

### Installation

From the `frontend/` directory, install dependencies:

```bash
npm install
```

### Development

To start the Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Production Build

To type-check with TypeScript and build production assets into `dist/`:

```bash
npm run build
```

### Preview Build

To preview the production build locally:

```bash
npm run preview
```

### Linting

To run the linter:

```bash
npm run lint
```
